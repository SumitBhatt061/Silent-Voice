# Silent Voice

A real-time Sign Language to Speech Translation system that converts hand gestures into text and speech using Computer Vision and Machine Learning.

## Features
- Static alphabet recognition
- Dynamic gesture recognition
- Real-time text generation
- Text-to-speech conversion
- MediaPipe hand tracking

## Technologies Used
- Python
- OpenCV
- MediaPipe
- TensorFlow
- LSTM
- Random Forest

## Project Architecture
1. Hand landmark detection
2. Feature extraction
3. Static gesture recognition
4. Dynamic gesture recognition
5. Text generation
6. Speech synthesis

## Future Improvements
- Larger vocabulary
- Better grammar correction
- Improved recognition accuracy
